# GitHub Issue and Pull Request

## Objective
Create a GitHub Issue to track a task and link it to a Pull Request.

## Procedure
1. Create an issue in the GitHub repository.
2. Create a new branch for the task.
3. Make a change and commit it.
4. Push the branch to GitHub.
5. Open a Pull Request and reference the issue.

## Result
The issue and Pull Request are linked for task tracking and code review.
