# Task 5: Trace Network Route

## Objective
Trace the route from my computer to a public website and count the network hops.

## Command
tracert google.com

## Results
- Destination: google.com
- Total hops: 14
- Hops with responses: 9
- Timed-out hops: 5
- Status: Trace complete

## Conclusion
Successfully traced the route to Google. The destination was reached at hop 14. Five hops timed out, while nine hops responded.
